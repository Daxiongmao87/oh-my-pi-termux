# Changelog

## 0.1.0

- ARM64 Termux launcher for the unmodified upstream Linux/glibc omp executable.
- Stable/exact-version updates with size, SHA-256, architecture and native-grep checks.
- Atomic activation, retained previous binary and offline rollback.
- Install/reinstall, launcher conflict handling, doctor and ownership-aware uninstall.
- Offline unit tests, opt-in device integration test and GitHub Actions workflow.
